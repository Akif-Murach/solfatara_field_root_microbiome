\f0\fs24 \cf0 MEGA12 Phylogenetic Tree Reconstruction\
=======================================\
\
Purpose\
-------\
Phylogenetic tree reconstruction of Hyaloscyphaceae sequences\
using the Neighbor-Joining method in MEGA12.\
\
\
Software\
--------\
MEGA12.1\
\
\
Input\
-----\
Alignment:\
    trimmed_0.6.fasta\
\
Alignment preprocessing:\
    Lowercase nucleotide characters were converted to uppercase\
    prior to alignment trimming because trimAl returned an error\
    for lowercase "n" characters.\
\
\
Phylogenetic Analysis Settings\
------------------------------\
\
Scope:\
    All Selected Taxa\
\
Statistical Method:\
    Neighbor-Joining\
\
Test of Phylogeny:\
    Bootstrap method\
\
Bootstrap Replicates:\
    1000\
\
Substitutions Type:\
    Nucleotide\
\
Model/Method:\
    Kimura 2-parameter model\
\
Substitutions to Include:\
    Transitions + Transversions\
\
Rates among Sites:\
    Uniform Rates\
\
Pattern among Lineages:\
    Same (Homogeneous)\
\
Gaps/Missing Data:\
    Pairwise deletion\
\
\
Computation\
-----------\
Number of Threads:\
    8\
\
\
Output\
------\
The resulting Neighbor-Joining tree was exported in Newick format\
for downstream visualization and phylogenetic signal analyses.}
